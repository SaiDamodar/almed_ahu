## 🎨 Design System

### **Colors**

#### Light Mode (White & Blue):
- Background: `#FAFAFA` (Light gray)
- Surface: `#FFFFFF` (White cards)
- Primary: `#2563EB` (Modern blue)
- Text: `#1F2937` (Dark gray)

#### Dark Mode (Black & Blue):
- Background: `#0F172A` (Deep blue-black)
- Surface: `#1E293B` (Dark blue-gray)
- Primary: `#3B82F6` (Bright blue)
- Text: `#F1F5F9` (Light gray)

#### Accent Colors:
- Success: `#10B981` (Green)
- Warning: `#F59E0B` (Orange)
- Error: `#EF4444` (Red)
- Temperature: `#F97316` (Orange)
- Humidity: `#06B6D4` (Cyan)

### **Typography**
- Display: Bold, 24-32px
- Body: Regular, 14-16px
- Small: 12px
- Font: System default (Roboto on Android/Linux)

### **Spacing**
- Card padding: 20-24px
- Element spacing: 12-20px
- Border radius: 12-24px
- No sharp corners anywhere

### **Components**
- **Cards**: Rounded (20-24px), subtle border, no heavy shadows
- **Buttons**: Rounded (12-16px), gradient for primary actions
- **Icons**: Rounded variants, 20-32px
- **Status chips**: Rounded (8-12px), colored borders
- **Touch targets**: Minimum 48x48px

## 🚀 How to Use

### Switch Themes:
Tap the sun/moon icon in the top-right corner of any screen.

### View Logs:
On the control screen, tap "System Logs" to expand/collapse.

### Control Setpoints:
Use the +/- buttons on temperature and humidity cards.

### Start/Stop System:
Tap the compact Start/Stop button in the top-right of control screen.
