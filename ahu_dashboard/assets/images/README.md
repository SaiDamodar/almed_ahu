# Logo Images

Please save the following **2 complete logo images** in this directory:

Both images contain the **green badge + ALMED text**, but with different text colors:

1. **logo_dark.png** - Complete logo with **DARK TEXT** (for light mode background)
2. **logo_light.png** - Complete logo with **LIGHT TEXT** (for dark mode background)

Both images should be saved as PNG files with transparent backgrounds for best results.

## Expected Files:

```
assets/images/
├── logo_dark.png     (Badge + ALMED with dark text)
└── logo_light.png    (Badge + ALMED with light text)
```

## Theme-Aware Display:

The app will automatically switch between the two logos based on the current theme:
- **Light Mode** → Shows `logo_dark.png` (dark text on light background)
- **Dark Mode** → Shows `logo_light.png` (light text on dark background)

The logo will display at the top of the login page with professional styling.
